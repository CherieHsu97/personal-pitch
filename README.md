# Personal Pitch

基于九个真实记者邀约与合作案例整理的话术 skill。适用于微信、私信、邮件、采访、引荐、合作邀约和旧关系激活。

核心：判断对方愿意参与的理由与顾虑，再提出具体的下一步。默认输出可直接发送的话术，不保证回复或成交。

## 在 Codex 中安装

下载仓库 ZIP 并解压，把含 SKILL.md 和 cases.md 的目录命名为 personal-pitch，放到 ~/.codex/skills/ 下。随后在新聊天中调用：

> 用 $personal-pitch 帮我写一段微信。对方是……我们之前……这次希望他……可以提的背景是……

也可以把本仓库链接交给 Codex，要求安装此 skill。

## 在其他 AI 工具中使用

将 SKILL.md 和 cases.md 一起提供给工具，要求按这些判断方法起草或修改话术。不同工具的技能安装方式可能不同。

## 内容

- SKILL.md：判断方法、表达偏好和输出要求。
- cases.md：九个匿名案例的背景、结果和方法。

这是匿名分享版，未公开人物身份、私人关系或采访敏感细节。案例结果为整理者报告；对具体措辞的因果作用仍需在实际使用中检验。
